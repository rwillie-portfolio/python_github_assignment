## Study Time Tracker

## Overview
The study time tracker is a simple Python program designed to help users track and estimate their weekly study hours based on daily input. This is accomplished through a user-friendly interface that allows students to reflect on their own study habits and better set their academic goals

## Features
User Input: Provides prompts to the user so that they may enter the number of hours studied each day.                                                                                     
Calculation: Computes the total estimated study hours for the week based on daily input.      
Error Handling: Provides feedback if the user enters a non-numeric value, ensuring proper use of code.

## How to Run
To execute this program:
1. Clone the repository to the local machine
2. Navigate to the project directory.
3. Run the program using Python
